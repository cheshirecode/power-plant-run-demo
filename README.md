# Power Plant Run

Static browser demo for a pixel-art soldier walking into a power plant with switchable visual styles.

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Local References

- `assets/steampunk-reference.png` came from the generated medieval/steampunk power plant image.
- `assets/cyberpunk-reference.png` was cropped from the cyberpunk quadrant of the generated collage.
- `assets/futuristic-reference.png` was cropped from the futuristic quadrant of the generated collage.
